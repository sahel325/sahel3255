RGB en CMYK

Een scherm maakt kleuren op een andere manier dan een printer. Bij schermen gebruik je RGB en bij vierkleurendruk gebruik je CMYK.

RGB: kleuren met licht

RGB staat voor rood, groen en blauw. Een beeldscherm mengt deze kleuren licht. Dat gebeurt bijvoorbeeld op mijn telefoon en op een computerscherm.

Bij 8 bits per kleurkanaal heeft elke kleur een waarde van 0 tot 255. Alles op 0 geeft zwart. Alles op 255 geeft wit. Kleuren maken door licht toe te voegen heet additief mengen.

CMYK: kleuren met inkt

CMYK staat voor cyaan, magenta, geel en zwart. Deze kleuren worden gebruikt bij drukwerk. De inkt neemt een deel van het licht op. Dit heet subtractief mengen. Zonder inkt zie je de kleur van het papier.

Een foto kan er op je telefoon anders uitzien dan op papier. Een printer kan niet alle kleuren van een scherm precies namaken.

Kleuren in mijn code

Voor deze website gebruik ik kleurcodes in CSS. Met background-color stel ik een achtergrondkleur in. De code #254666 is bijvoorbeeld het blauw bovenaan mijn website.
